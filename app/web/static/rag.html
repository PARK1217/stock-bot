📊 예측 성적표 — 통계 로딩…

이 탭의 목적: "이 봇의 예측을 얼마나 믿어도 되나"를 숫자 하나로.
파이프라인: 매일 예측 생성 → ⏳ 만기 대기(7·14·21영업일) → 만기 도달 시 실제 가격과 비교·채점 → 건별 기록은 ✅ 채점 내역 탭에, 그 누적 통계가 바로 이 화면입니다.
· 방향 적중률 = 오른다/내린다 베팅이 맞은 비율(50%대면 동전던지기 수준 → 예측은 참고만) · 범위 적중률 = 실제 가격이 예측 밴드(P10~P90) 안에 들어온 비율(높으면 변동폭 추정은 쓸만).

✅ 채점 내역 — 예측 vs 실제

이 탭의 목적: 📊 통계의 근거(영수증) — 과거 예측 하나하나를 실제 결과와 대조.
만기가 지난 예측마다 "그때 뭐라고 예측했나 → 실제론 어떻게 됐나"를 기록합니다. 방향=오른다/내린다 베팅 일치 · 범위=실제가가 예측밴드(P10~P90) 안 · 빗나감엔 💡추정 이유. 여기 건들이 쌓여 📊 성적표의 적중률이 됩니다.
