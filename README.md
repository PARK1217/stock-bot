> **배당 + 성장 균형을 지향하는 "반자동" 개인 투자 비서.**
> 봇이 분석·예측·제안을 하고, **실제 매수/매도는 사람이 승인**합니다. 미국장·한국장을 24시간 같이 보고,
> 어려운 건 **주린이(주식 초보)도 알아듣게** 풀어줍니다.

> 💡 **한 줄 요약(포트폴리오 관점)** — 증권사 3계좌(토스·한투 ISA·연금)를 하나의 백엔드로 추상화하고,
> **"검증 없이 실돈을 맡기지 않는다"** 는 원칙으로 *모의계좌에서 전략을 충분히 검증한 뒤 → 실계좌 자동매매로 넘어가는*
> 단계적 파이프라인을 직접 설계·운영하는 프로젝트. 데이터 수집 → 분석(전략·확률예측·뉴스감성) →
> 리스크 검증 → 제안 → (사람 승인) → 기록·알림까지 한 바퀴를 돌립니다.

## 🎯 왜 만들었나 (목적과 방향성)

- **한 화면에서 내 돈 전부 보기** — 토스(미국주식)·한국투자증권(ISA·연금) 계좌를 한 대시보드로.
- **감(感)이 아니라 근거로** — 추세·뉴스 감성·확률 예측을 숫자로 보여주고, **맞았는지 스스로 채점**해 신뢰도를 쌓는다.
- **완전 자동매매로 가되, 검증을 다 거치고 간다** — 최종 목표는 실계좌 자동매매지만, 그전에 **모의로 충분히 의심**한다.
- **초보 친화** — 모든 어려운 용어에 쉬운 풀이를 붙인다(아래 [용어 풀이](#-주린이-용어-풀이)).

**투자 성향 기준**: 배당 + 성장 균형 · 장기 + 중기 + 단타 혼합 · 낙폭 −25%까지는 견딘다 · 레버리지·단타는 "버킷(한도)"으로만 제한적으로.

## 🚦 지금 어디까지 왔나 — 개발 단계 (로드맵)

이 프로젝트는 **"검증 → 실전"** 두 트랙으로 **단계적으로** 간다.
실돈 자동매매가 최종 목적이지만, **검증 없이 실돈을 자동으로 맡기지 않는다**는 게 제1원칙이다.

### 🧪 트랙 A — 모의계좌 · *지금 주력: 검증과 시행착오*
> "이 전략을 실돈에 올려도 되는가?"에 **숫자로 답할 수 있을 때까지** 두들겨 보는 단계.

- 가상 자본으로 **전략을 24시간 라이브 모의 운용** → 실제 시세·체결 흐름에서 어떻게 작동하는지 관찰.
- **백테스트(과거 데이터)·워크포워드·수수료 스윕**으로 통계적 유의성을 확인해 **과최적화를 걸러낸다.**
- 여기서 나오는 **시행착오**(전략 버그, 리밸런싱 타이밍, 체결 슬리피지, 통합증거금 캡…)를 잡는 게 지금 할 일.
- 실제로 백테스트로 *"타이밍 단타는 장기 보유 대비 진다"* 를 확인하고 현재 전략을 유지하기로 한 것도 이 트랙의 결과물.

### 🏦 트랙 B — 실계좌 · *준비 단계: 아직 자동매매는 안 함*
> 지금 실계좌는 **조회 + 반자동 제안**까지만. 자동 집행은 **의도적으로 잠가 뒀다.**

- 현재: 토스(미국)·한투(ISA·연금) 잔고·거래내역 **조회** + 봇이 **제안** → **사람이 승인·집행.**
- 실거래 자동집행은 안전장치로 잠금 상태 — `TOSS_ALLOW_LIVE` off, 한투 자동매매 엔진은 `paper`(모의) 강제.
- 로드맵: **트랙 A 검증이 통과되면 → 소액·단일종목부터** 실계좌 자동집행을 **점진적으로** 개방.

### 단계 요약

| 단계 | 상태 | 무엇을 하나 | 다음 단계로 가는 통과 기준 |
|---|---|---|---|
| ① 모의 검증 | 🟢 **진행 중** | 가상자본 24h 운용 + 백테스트·워크포워드 | 샤프·MDD 등 리스크·수익 지표가 벤치마크(SPY 등)를 유의미하게 상회 |
| ② 반자동 실계좌 | 🟢 **운영 중** | 실계좌 조회 + 사람승인용 제안 | 제안 품질·계좌별 매수가능 판정 안정화 |
| ③ 실계좌 자동집행 | ⚪ **준비 중** | 검증된 전략을 소액부터 자동 매매 | 트랙 A 통과 + 한도·킬스위치 등 안전장치 완비 |

## 🧰 무엇을 하나 (핵심 기능)

| 기능 | 설명 (쉬운 말) |
|---|---|
| **실계좌 통합 보기** | 토스(미국)·한투(ISA·연금) 현금·보유·주문·거래내역을 한눈에 |
| **자산 흐름 그래프** | 전체 + 계좌별로 내 돈이 어떻게 늘고 줄었는지 시계열로 |

| **뉴스 감성 이슈** | 종목별 뉴스를 모아 🟢긍정/🔴부정/⚪중립 + **실제 주가 반영 여부**까지 |
| **모의 자동매매** | 가상 자본으로 전략을 24시간 돌려 성적 검증 (실돈 X) |

| **분석 챗봇** | 보유·스크리너·예측·계좌제약을 근거로 답하는 주린이용 LLM 챗봇 |
| **계좌별 매수가능 판정** | 연금·ISA·소수점·일반 계좌에서 이 종목을 살 수 있는지 자동 판정 |
| **RAG 평가 페이지** | 예측 검증·검증완료·진행중·챗봇 정확도·이슈 히스토리를 별도 화면으로 |

화면은 **모바일 앱(PWA)** 으로 설치 가능 — 홈화면에 아이콘으로.

## 🏗️ 시스템 구조

```
app/
├─ bot/                    ← 두뇌 (분석·전략·스케줄러)
│  ├─ brokers/             증권사 어댑터 (공통 인터페이스로 추상화)
│  │   ├─ base.py          BrokerAdapter (Position·Balance·OrderResult)
│  │   ├─ toss.py          토스증권 — 미국주식 실계좌 (조회·주문)
│  │   └─ kis.py           한국투자증권 — 모의 자동매매 + ISA·연금 실계좌 조회
│  ├─ strategies/          코어-새틀라이트 + 밴드 리밸런싱 전략
│  ├─ risk/rules.py        리스크 게이트 (비중·일일한도·손절)
│  ├─ papertrader.py       모의 자동매매 엔진 (MA50 추세필터 + SPY 레짐)
│  ├─ forecast.py          확률 예측 (몬테카를로) + 자기예측 채점
│  ├─ screener.py          추세 스크리너 (모멘텀·추세 점수)
│  ├─ news.py / sentiment.py  뉴스 감성 (HF FinBERT 점수 + Groq 요약)
│  ├─ macro.py             거시(금리·원자재) 컨텍스트
│  ├─ eligibility.py / accounts.py  계좌별 매수가능 규칙 + 계좌 단일출처
│  ├─ realized.py          실현손익(매도 기준) 집계
│  ├─ chateval.py          챗봇 콜 자동 채점
│  ├─ names.py             종목명 해석·자동학습(한글 우선)
│  ├─ glossary.py          주린이 용어 사전 (단일 출처)
│  ├─ notify/              디스코드·텔레그램 알림
│  ├─ storage/             Postgres 모델·세션
│  └─ main.py              명령(balance·snapshot·run…) + 스케줄러
└─ web/                    ← 얼굴 (대시보드)
   ├─ server.py            FastAPI API + 비밀번호 인증
   └─ static/
      ├─ index.html        대시보드 (실계좌·모의·감시·AI 탭)
      └─ rag.html          RAG 평가 (예측 검증·챗봇 정확도·이슈 히스토리)
```

**데이터 흐름**
```
시세·뉴스 수집 → 분석(전략·예측·감성) → 리스크 검증 → 제안 생성
        → 사람이 승인 → 주문 → DB 기록 + 디스코드 알림
        → 대시보드/챗봇이 DB·캐시를 읽어 보여줌 (항상 즉시)
```

**구동 방식**: `docker compose` 4개 컨테이너
- `db`(Postgres, 기록 저장) · `redis`(캐시) · `bot`(스케줄러·분석) · `web`(대시보드)
- 집 서버 LXC에서 24시간 상주, `cloudflared` 터널로 외부 접속(비밀번호 보호).

**눈여겨볼 설계 결정 (엔지니어링 관점)**
- **브로커 추상화** — 토스·한투를 `BrokerAdapter` 하나로 통일해 전략/화면이 증권사 세부를 몰라도 됨.
- **단일 출처(Single Source of Truth)** — 계좌번호(`accounts.py`)·용어(`glossary.py`)를 한 곳에 모아 14곳 복붙 제거.
- **정직한 예측** — 단정 대신 몬테카를로로 "확률·범위"를 내고, 만기 후 **스스로 채점**해 신뢰도를 축적.
- **캐시·배치로 무료 한도 방어** — 시세/토큰/뉴스 Redis 캐시 + FinBERT 배치 1콜로 50건 처리.
- **안전 우선 기본값** — 실거래는 명시적 플래그로만 열리고, 자동매매 엔진은 모의 강제.

## ⚠️ 제약과 안전장치 (꼭 읽기)

- **수익 보장 없음.** 어떤 봇도 미래를 못 맞힙니다. 예측은 "확률·참고치"일 뿐.
- **반자동이 기본** — 실거래 주문은 `TOSS_ALLOW_LIVE` 같은 명시적 동의 + 사람 승인이 있어야만.
- **한투 자동매매는 모의 강제** — 자동매매 엔진은 가상계좌(`paper`)로만 돕니다(실돈 자동매매 X).
- **API의 벽**(토스 OpenAPI 한계, 못 하는 것):
  - 소수점/미니스탁 주문·조회 → **불가**(앱 전용)
  - 외화주식 **환차익** → 손익에 미반영(취득환율 미제공) → 화면에 "토스 앱 참고" 안내
- **LLM 무료 한도** — Groq 일일 토큰 한도가 있어, 뉴스 요약은 가벼운 모델 + 캐시 + 배치로 우회.
- **비밀·키는 절대 커밋 안 함** — `.env`(gitignore). 저장소엔 키가 없습니다.

## 📚 주린이 용어 풀이

<details>
<summary>봇 곳곳(툴팁·챗봇·알림)에서 쓰는 핵심 용어를 쉽게 — 펼쳐보기 (이 프로젝트의 "초보 친화" 설계 원칙을 보여주는 부분)</summary>

- **배당** — 회사가 번 돈을 주주에게 나눠주는 것. (예금 이자 비슷)
- **ETF** — 여러 종목을 한 바구니에 담은 묶음 상품. 하나 사면 분산투자.
- **룩스루(look-through)** — ETF "속을 뚫어" 실제로 어떤 기업에 얼마나 담겼는지 보는 것.
- **모멘텀 / 추세** — 최근 잘 오르던 흐름. 추세=오르는 방향이 이어지는 상태.
- **정배열** — 단기·장기 평균선이 위→아래로 가지런(상승 흐름의 신호).
- **MA50** — 최근 50일 평균 가격선. 이 위면 중기 상승, 아래면 약세로 본다.
- **리밸런싱 / 밴드 리밸런싱** — 목표 비중에서 일정 폭(±밴드) 벗어나면 되돌리는 것.
- **레버리지 / 인버스** — 2배·3배로 키운 / 반대로(하락 베팅) 상품. **변동 큼·위험**.
- **MDD(최대낙폭)** — 고점 대비 가장 많이 떨어진 폭. "최악에 얼마까지" 견디는 기준.
- **샤프지수** — 위험(흔들림) 대비 수익이 얼마나 효율적인가.
- **백테스트** — 과거 데이터로 전략을 미리 돌려보는 모의 실험.
- **워크포워드** — 과거로 만든 규칙을 그 다음 기간에 검증(과최적화 방지).
- **몬테카를로** — 미래 경로를 수천 번 무작위로 돌려 "확률·범위"를 뽑는 방법.
- **레짐** — 시장 국면(상승장/하락장). 국면 따라 전략을 다르게.
- **통합증거금** — 한 계좌의 예수금으로 여러 시장을 함께 거래하는 것.
- **소수점** — 1주가 비싼 주식을 0.1주처럼 쪼개 사는 것(토스 앱 전용).
- **감성 극성** — 뉴스가 🟢긍정/🔴부정/⚪중립 중 어느 쪽인지.
- **반영/역행/소화/횡보** — 이슈 방향대로 주가가 움직였나(반영=영향 있음, 역행/소화=반대로, 횡보=영향 거의 없음).

> 전체 용어는 대시보드 **📖 쉬운 용어** 버튼 또는 `glossary.py` 참고.

</details>
